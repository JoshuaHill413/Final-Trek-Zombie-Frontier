# Final Trek: Zombie Frontier

A survival game built in Unity, inspired by the classic "Oregon Trail" 
structure and reimagined with a zombie-apocalypse setting. Navigate a 
scrolling map across the country, manage dwindling resources, and survive 
three interactive minigames along the way.

CS2 End-of-Year Project
Team: Quinn Marcello, Nicholas Doan, Samuel Ferrera, Josh Hill

My Contributions
- Built the majority of the core scrolling/map traversal mechanism
- Created most of the custom artwork used throughout the game
- Implemented the transitions between story/travel events
- Pitched the initial concept to the team and led a beta release to peers, 
  gathering feedback that shaped revisions before final submission

Features
- Complex scrolling map system driving progression across the trail
- Three interactive minigames (repair, resource, combat)
- Resource management with realistic depletion and difficulty scaling
- Fully custom artwork and UI
